O que é o CSS?

O CSS significa Cascading Style Sheets, ou Folhas de estilo em cascata.

Sobre o CSS

Linguagem responsável por definir a aparência visual e organização dos elementos na tela.

Como aplicar o CSS?

Para o CSS, temos três abordagens.

  • CSS Inline
  • CSS Interno
  • CSS Externo

O que da pra fazer com o CSS?

O CSS Não serve apenas para colocar cor na página. Ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamenstos
  • sombras
  • bordas
  • posicionamento
  • responsividade
  • animações
  • transições

Aplicando o CSS Inline

Nessa aboredagem, o CSS é colocado diretamente no elemento HTML através do atributo style

Aplicando o CSS Interno

Nessa abordagem, o CSS é aplicado dentro de uma tag < style ≷ dentro do < head ≷ do documento HTML.

Aplicando o CSS Externo

Nessa abordagem, os estilos do CSS ficam concentrados em um arquivo separado.

Para conectar esses arquivo ao HTML, utilizamos o link no < head ≷ da pagina
